# 确定性随机与差分验证

运行 `python -m pip install -r scripts/requirements-reference.txt` 和 `python scripts/differential.py`。无需数据库，构建 MoonBit native 测试入口并用固定种子 2026101819 生成输入；可用 --seed 和 --count 复现或扩展。生成的二进制语料、输出和报告保存在忽略的 .artifacts/differential-*，不写入公共仓库。

默认包含 805 个类型案例、34 个双向 LZ4 块和 1600 个类型／压缩变异案例。类型覆盖全部已支持标量及深度最多四层的 list、set、map、tuple、UDT，含 NULL 字段、4096 位整数、精确 decimal、IPv4／IPv6、UUID 和纳秒时间。独立驱动为 cassandra-driver 3.30.0，压缩参考为 lz4 4.4.5。

Python 先独立序列化；MoonBit 解码后输出结构化语义描述，并重新编码；Python 同时比较语义描述和重新解码的值，避免仅做同一实现的编解码回环。浮点通过 IEEE 位模式核对，整数不经过浮点；timestamp 的完整边界另外由 conversion_reference.py 和实际数据库互操作覆盖。LZ4 两方向分别由对方解压。131072 和 400000 字节消息按 v5 单块 131071 字节上限分块。

变异从有效类型、值和 LZ4 块出发，混合截断、翻转、追加、随机字节和非法输出长度。部分变异仍是合法值，允许成功解码，不将接受任意变异一概判为错误。原生进程有 90 秒外部超时，语料最多 64 MiB、20000 个案例，LZ4 输出由协议上限约束。随机测试只能发现已覆盖输入中的问题，不是对全部异常输入的数学证明。

`moon test --target native --deny-warn` 另运行固定种子的两类状态测试：

- 40 个正文以随机位置切为外层帧，覆盖普通／LZ4、400000 字节重组和消息头跨片；逐片翻转随机一位，验证 CRC 拒绝损坏。
- 32 轮真实本地 TCP，每轮 12 个并发请求，随机重排响应、取消请求，并将 TCP 输出随机拆为 1–31 字节；部分轮次在下一帧头只写三字节后 EOF。独立请求 ID 模型核对每个成功或失败，不允许结果串到其他请求；每轮核对 pending、废弃请求、等待数量、在途数量和字节全部归零。

差分核对发现并缩减了三类已有遗漏，最小样例保存在 types/legacy_value_test.mbt：布尔 0x02／0xff 应为 true；Int 零长度应是 Empty 而非 NULL 或截断错误；仅含第一字段的 UDT／tuple 允许尾部字段缺失。修正依据为固定提交的 v5 规范第 5 节、5.4 节和第 6 节，以及独立驱动的对应解码；短字段的部分长度仍拒绝。原有错误地要求布尔只能为 0／1 的测试已改为真正的多字节非法载荷。

Windows 和 Linux CI 均运行该差分脚本及单元／状态测试。运行失败时保留语料目录和案例序号，先从该案例及其类型树缩减，再将最小失败输入加入普通回归；发现新问题应修复后再更新验收结论。

静态复核又发现一类分配放大风险：省略字段的宽 UDT 可以在每行展开大量 NULL，单靠响应字节上限和单个集合元素上限不足以限制整页分配。修复增加整页共享的 Value 节点预算，回归输入仅用两个空 UDT 单元格即可验证跨行累计、恰好耗尽和超限拒绝；另覆盖嵌套 map／list／tuple、显式 NULL 和零列空页。新增回归已通过 native 检查和运行，并重新通过种子 2026101819／2026101820 的独立差分验证。
